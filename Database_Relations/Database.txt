Relational Database
A relational database is a collection of tables.

A table is:
like a spreadsheet where data is organized into rows and columns
used to represent an entity or a relationship between entities.

What is an entity?
An entity is an object or concept that can be described by many attributes.

RDBMS
is a software that interacts with the underlying hardware and OS to physically store and manage data in relational databases (Firebird, MySQL, PostgreSQL, SQLite).

Three SQL clauses:
SELECT: The SELECT clause specifies the columns you want to retrieve from a table.
FROM: The FROM clause specifies the source you want to retrieve data from.
WHERE: The WHERE clause allows you to specify conditions to filter the data retrieved by the SELECT clause.

Aggregation
Aggregation is about perfoming calculations on a set of rows to produce a single result 
GROUP BY clause:
- Remember to include the column following the GROUP BY clause in the SELECT statement
- Remember to exclude from the SELECT clause any columns that are neither in the GROUP BY clause or the aggregate functions

Create a table 
- CREATE TABLE: command hamndles table creation
- Syntax:
  CREATE TABLE table_name (
    column_Name1 datatype [optional_parameters]
    column_Name2 datatype [optional_parameters]
    PRIMARY KEY (column_NameX)
  )

Alter or drop a table
ALTER TABLE command helps you update table structure
- Syntax:
  ALTER TABLE product
  ADD serial_number TEXT
- Syntax:
    DROP TABLE product

Add data to a table
INSERT INTO command helps you add data into table
- Syntax:
  INSERT INTO table_name(column1,column2)
  VALUES (value1,value2)

Delete or update data in a table
DELETE command deletes a table
- Syntax: DELETE FROM table_name
          WHERE product_id = 2
UPDATE .. SET command updates data in a table
- Syntax: UPDATE table_name
          SET column1 = newValue1
              column2 = newValue2
          WHERE condition
